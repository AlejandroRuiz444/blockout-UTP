# Blockout desde una cámara móvil

Proyecto de Visión por Computador (Universidad Tecnológica de Pereira, 2026-II): visualización 3D interactiva inspirada en [BlockOut](https://codeberg.org/shuang886/BlockOut), con la cadena de proyección (`M`, `[R|t]`, `K`, recorte contra el plano cercano y división en perspectiva) implementada por el equipo, en HTML + JavaScript + Canvas 2D, sin dependencias.

> **Repositorio en construcción.** El código se incorpora por etapas, con *pull requests* revisados entre los integrantes. Este README se reemplaza por el definitivo (instalación, controles, tests y limitaciones) en la última etapa.
